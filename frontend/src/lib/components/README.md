# components

Owned UI primitives and compositions. Receive values and callbacks; no services,
native SDKs, features or workbench imports. Live foundations are under
`primitives/`, `layout/`, `forms/`, `feedback/`, `navigation/`, `overlays/`,
`collections/`, `data-display/`, `content/`, and `patterns/`; more components
arrive with consuming slices.

Representative rendered contracts live in `rendered.browser.test.ts` and run
with `npm run test:browser` in Chromium. They cover DOM semantics and events;
the gallery remains the broader visual inventory.
