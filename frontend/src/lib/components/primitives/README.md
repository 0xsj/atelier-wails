# primitives

Foundational visual components. `Button`, `IconButton`, `Icon`, `Surface`,
`Separator`, `Text`, `Heading`, `Label` and `Kbd` are live primitives; they read
semantic tokens and own only presentation concerns. `Icon` frames caller-supplied
SVG paths on the control size scale and is decorative unless given a label.
Complex interaction primitives wrap Bits UI as they are introduced.
