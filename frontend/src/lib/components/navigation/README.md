# navigation

`Tabs`, `TabPanel`, `DropdownMenu`, `ContextMenu`, `Toggle`, `ToggleGroup`,
`Collapsible`, `Accordion`, and `Breadcrumb` provide view-local keyboard
navigation with Atelier-owned desktop styling. `Toolbar`, `ToolbarButton` and
`ToolbarGroup` wrap Bits UI's roving-focus toolbar so a row of actions is one
tab stop. They own keyboard semantics, not application navigation policy.
